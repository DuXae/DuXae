# Проекты

Репозиторий с программами для расчёта наклонных подъёмных платформ и подъёмников по
геометрии лестницы.

| Проект | Что это | Запуск |
|---|---|---|
| [`platform-app/`](platform-app/) | Веб-программа: 30 ступеней, пандусы и НПУ, ограничения 10 м и 30°, схема подъёма, сохранение в JSON, настройки | открыть `platform-app/index.html` |
| [`platformcalc/`](platformcalc/) | Ядро и консольный расчёт на Python: отчёт, JSON, библиотека | `python -m platformcalc.cli --steps 12 --rise 160 --tread 320` |

Основной проект — `platform-app`: интерфейс, повторяющий порядок работы конструктора
(пошаговый ввод ступеней, площадки, ширина марша, въездной пандус). `platformcalc`
остаётся как независимая реализация того же расчёта на Python для отчётов и выгрузок.

## Общая модель

Обе программы считают одинаково: сумма высот ступеней даёт длину подъёма, сумма проступей
без последней — горизонтальную длину, угол — `arctg(H/L)`. Дальше длина направляющей,
габарит платформы, тяговое усилие, мощность привода и нагрузка на крепления.
Подробности — в README каждого проекта.
