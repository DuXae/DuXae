# Калькулятор наклонного подъёмника для лестницы

Программа считает параметры наклонного подъёмника по размерам лестницы: угол наклона,
длину направляющей, точки крепления, тяговое усилие, мощность привода и ориентировочную
стоимость. Две части с одинаковой математикой:

- `liftcalc/` — ядро на Python для инженерного расчёта и выгрузки в JSON;
- `web/` — страница-калькулятор для клиентов, открывается двойным щелчком.

## Что считает

| Параметр | Как получается |
|---|---|
| Угол наклона α | `arctg(H / L)`, где H — высота подъёма, L — горизонтальная проекция |
| Длина по наклону | `√(H² + L²)` |
| Направляющая | длина по наклону + 0,35 м с каждой стороны + 1,6 м на поворот |
| Точки крепления | шаг 1,5 м, минимум две |
| Шаг ступени | `H / число ступеней`, норма 150–200 мм |
| Тяговое усилие | `m·g·(sin α + 0,02·cos α) + m·a` |
| Мощность привода | `F·v / 0,75` |
| Нагрузка на крепление | `m·g·cos α / число точек` |
| Цена | база 320 000 ₽ за 3 м, далее 42 000 ₽/м, поворот 90 000 ₽, платформа 50 000 ₽, монтаж 12 % |

Проверки: угол вне 15–45°, свободная ширина меньше 0,9 м и неверный шаг ступени дают
предупреждения; первые две — ошибки, при которых проект невыполним.

## Запуск

### Веб-страница

Откройте `web/index.html` в браузере. Расчёт идёт сразу при вводе, кнопка «Печать»
готовит лист для клиента. Сервер не нужен.

Чтобы выложить в интернет, включите GitHub Pages для ветки `main`, папка `/web`
(репозиторий → Settings → Pages).

### Консоль

```bash
python -m liftcalc.cli --height 2.8 --run 3.4 --width 1.1 --steps 15
```

Параметры: `--height`, `--run`, `--width`, `--steps`, `--track straight|turn`,
`--kind platform|seat`, `--payload`, `--json`, `--out файл`.

Без аргументов программа спрашивает значения по очереди:

```bash
python -m liftcalc.cli
```

Код возврата: `0` — проект выполним, `1` — есть ошибки в геометрии, `2` — неверные данные.

### Библиотека

```python
from liftcalc import LiftInput, compute

result = compute(LiftInput(height_m=2.8, run_m=3.4, width_m=1.1, steps=15))
print(result.angle_deg, result.price.total)
print(result.to_dict())  # готово к JSON
```

```bash
python -m unittest discover -s tests -t .
```

## Настройка под производство

Цены и нормативы собраны в начале файлов:

- `liftcalc/calc.py` — `PRICE_*`, `MIN_ANGLE_DEG`, `MAX_ANGLE_DEG`, скорость, массы;
- `web/app.js` — те же константы в блоке `PRICE` и выше.

Правьте оба файла согласованно. Проверить, что расчёт совпадает, можно так:

```bash
node -e "console.log(require('./web/app.js').compute({height:2.8,run:3.4,width:1.1,steps:15,track:'straight',kind:'platform',payload:250}).price.total)"
```

## Ограничения

Расчёт ориентировочный. Он не учитывает доставку, демонтаж, подготовку основания,
фактическое состояние ступеней и требования конкретного производителя оборудования.
Цена — модель на основе прайса, а не коммерческое предложение.
