# Платформа — расчёт наклонной подъёмной платформы

Веб-программа для конструктора: по размерам ступеней лестницы определяет параметры
наклонной подъёмной платформы. Работает локально в браузере, без сервера и без входа.

Открыть: двойной щелчок по `index.html`.

## Возможности

- Таблица на 30 ступеней: высота подступенка и длина проступи для каждой, без пропусков.
- Последняя ступень без проступи — её роль играет верхняя площадка.
- Площадки: нижняя, верхняя, ширина марша.
- Въездной пандус: обычный, удлинённый на 50, 100, 150 мм и отдельная галочка
  «укороченная площадка НПУ» (складывается с выбранным пандусом).
- Ограничения платформ: длина подъёма до 10 м, угол до 30°. Нарушение — ошибка,
  расчёт помечается как непроходящий.
- Результат пересчитывается при вводе; схема подъёма рисуется тут же.
- Файл → «Сохранить» выгружает проект в JSON, «Загрузить» возвращает его.
- Настройка → «Параметры»: ограничения, длина платформы, шаг креплений, скорость,
  грузоподъёмность. Значения сохраняются в браузере.
- Печать: Ctrl+P даёт лист без меню и кнопок.

## Что считается

| Параметр | Формула |
|---|---|
| Длина подъёма H | сумма высот всех ступеней |
| Длина по ступеням L | сумма проступей всех ступеней, кроме последней |
| Угол подъёма α | `arctg(H / L)` |
| Длина по наклону | `√(H² + L²)` |
| Направляющая | длина по наклону + 250 мм с каждой стороны |
| Точки крепления | шаг 1,5 м, минимум две |
| Длина платформы | 1100 мм + добавка пандуса − 150 мм при НПУ |
| Ширина платформы | ширина марша − 100 мм, но не меньше 800 мм |
| Тяговое усилие | `m·g·(sin α + 0,02·cos α)` |
| Мощность привода | `F·v / 0,75` при скорости 0,1 м/с |
| Нагрузка на крепление | `m·g·cos α / число точек` |

Предупреждения: пропуск ступени, разброс высот больше 5 мм, проступь меньше 250 мм,
средняя ступень вне 100–200 мм, ширина марша меньше 900 мм.

## Настройки

Окно «Настройка → Параметры», значения хранятся в `localStorage`:

| Ключ | Смысл | По умолчанию |
|---|---|---|
| `maxRiseMm` | максимальная длина подъёма, мм | 10 000 |
| `maxAngleDeg` | максимальный угол, ° | 30 |
| `minWidthMm` | минимальная ширина марша, мм | 900 |
| `platformBaseMm` | длина платформы, мм | 1100 |
| `npuDeltaMm` | поправка НПУ, мм | −150 |
| `supportSpacingMm` | шаг точек крепления, мм | 1500 |
| `speedMps` | скорость платформы, м/с | 0,1 |
| `payloadKg` | грузоподъёмность, кг | 250 |

## Тесты

```bash
node tests/engine.test.js
```

22 теста: геометрия, пандусы и НПУ, ограничения 10 м и 30°, пропуск ступеней,
предупреждения, переопределение настроек. Движок — чистый модуль без DOM,
поэтому тестируется в Node без браузера.

## Структура

```
platform-app/
  index.html      разметка страницы
  css/app.css     оформление
  js/engine.js    расчёт (UMD: браузер и Node)
  js/ui.js        таблица, результат, схема, файлы, настройки
  vendor/         Bootstrap 5.2.3 (MIT), локально
  tests/          engine.test.js
```

## Формат файла проекта

```json
{
  "format": "platform-app/1",
  "settings": { "maxAngleDeg": 30 },
  "input": {
    "rows": [{ "rise": "160", "tread": "320" }],
    "lower": "1000", "upper": "1000", "width": "1100",
    "ramp": "0", "npu": false
  }
}
```

## Ограничения

Расчёт ориентировочный: не учитываются несущая способность ступеней, кривизна трассы
в плане, материал основания и требования конкретного производителя. Длины платформы
для разных пандусов — модельные, их нужно сверить с документацией на оборудование.

Оформление и код написаны самостоятельно; сторонние библиотеки — Bootstrap 5.2.3 (MIT),
шрифт Inter (OFL) подключается с Google Fonts и при отсутствии сети заменяется системным.
