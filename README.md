# Расчёт наклонной подъёмной платформы

Программа для конструктора и менеджера: по размерам ступеней лестницы считает параметры
наклонной подъёмной платформы — высоту и угол подъёма, длину направляющей, габарит
платформы, нагрузки и время перемещения. Две части с одинаковой математикой:

- `platformcalc/` — ядро на Python для инженерного расчёта, выгрузки в JSON и печати отчёта;
- `web/` — страница-калькулятор, открывается двойным щелчком, без сервера.

За основу взят порядок работы программы «Лесенка» с сайта `лесенка74.рф`: пошаговый ввод
высоты и проступи каждой ступени, длины площадок, ширины марша и типа въездного пандуса.
Код, тексты и оформление исходного сайта не использованы — это самостоятельная реализация
с теми же инженерными допущениями.

## Что вводится

| Поле | Смысл |
|---|---|
| Высота ступени | подступенок каждой ступени, мм (может отличаться) |
| Длина проступи | ширина ступени по ходу движения, мм; у последней не задаётся |
| Длина нижней площадки | свободное место перед первой ступенью, мм |
| Длина верхней площадки | место на верхнем этаже, мм |
| Ширина марша | ширина лестницы в свету, мм |
| Въездной пандус | обычный, удлинённый на 50/100/150 мм, укороченная площадка НПУ |
| Грузоподъёмность | масса человека с коляской, кг |

До 30 ступеней.

## Что считается

| Параметр | Формула |
|---|---|
| Высота подъёма H | сумма высот всех ступеней |
| Длина по ступеням L | сумма проступей всех ступеней, кроме последней |
| Угол подъёма α | `arctg(H / L)` |
| Длина по наклону | `√(H² + L²)` |
| Направляющая | длина по наклону + 250 мм с каждой стороны |
| Точки крепления | шаг 1,5 м, минимум две |
| Длина платформы | 1100 мм + удлинение пандуса (или −150 мм для НПУ) |
| Ширина платформы | ширина марша − 100 мм, но не меньше 800 мм |
| Тяговое усилие | `m·g·(sin α + 0,02·cos α)` |
| Мощность привода | `F·v / 0,75`, скорость 0,1 м/с |
| Нагрузка на крепление | `m·g·cos α / число точек` |

Ограничения платформы: подъём до 10 м, угол до 30°. Нарушение — ошибка, при которой расчёт
не проходит. Отдельные предупреждения: ширина марша меньше 900 мм, разброс высот ступеней
больше 5 мм, проступь меньше 250 мм, средняя ступень вне 100–200 мм.

## Запуск

### Веб-страница

Откройте `web/index.html`. Схема подъёма и все параметры пересчитываются при вводе,
кнопка «Печать» готовит лист для клиента.

Чтобы выложить в интернет: Settings → Pages → ветка `main`, папка `/web`.

### Консоль

```bash
# 12 одинаковых ступеней 160×320 мм
python -m platformcalc.cli --steps 12 --rise 160 --tread 320

# разные ступени: высота:проступь, сколько нужно
python -m platformcalc.cli --step 170:300 --step 175:295 --step 180:290 \
    --lower 1200 --upper 900 --width 1100 --ramp ext100
```

Параметры: `--step`, `--steps`, `--rise`, `--tread`, `--lower`, `--upper`, `--width`,
`--ramp`, `--payload`, `--json`, `--out`.

Без аргументов программа спрашивает данные построчно. Код возврата: `0` — расчёт проходит,
`1` — не проходит по ограничениям, `2` — неверные данные.

### Библиотека

```python
from platformcalc import StairInput, Step, compute

data = StairInput(
    steps=(Step(160, 320), Step(160, 320), Step(160, 0)),  # последняя без проступи
    lower_platform_mm=1000,
    upper_platform_mm=1000,
    width_mm=1100,
)
result = compute(data)
print(result.angle_deg, result.rail_length_mm)
print(result.to_dict())  # готово к JSON
```


## Настройка под производство

Константы собраны в начале файлов и продублированы в двух местах:

- `platformcalc/calc.py` — `MAX_RISE_MM`, `MAX_ANGLE_DEG`, `PLATFORM_BASE_MM`, `RAMP_DELTA_MM`,
  скорость, масса платформы;
- `web/app.js` — те же значения в начале файла.

Сверить расчёт двух реализаций:

```bash
node -e "console.log(require('./web/app.js').compute({steps:[{rise:160,tread:320}],lower:1000,upper:1000,width:1100,payload:250,ramp:'normal'}).angleDeg)"
```

## Ограничения

Расчёт ориентировочный и не заменяет выезд на объект: не учитываются несущая способность
ступеней, материал основания, кривизна трассы в плане, требования конкретного производителя.
Длины платформы для разных пандусов — модельные, уточните их по документации на оборудование.
